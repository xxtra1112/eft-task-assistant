# EFT 任务助手

**逃离塔科夫任务、地图与藏身处规划工具。** 通过游戏内截图识别商人任务，跟踪每项要求，整理任务钥匙与藏身处升级材料，并在地图上查看任务点位。

## 功能一览

- **截图识别：** 从你授权的游戏截图文件夹导入截图，识别商人页面并匹配任务。成功匹配的任务会自动加入清单，并显示本次识别记录。
- **任务追踪：** 按商人或地图筛选；把任务要求分别勾选或填写进度计数；支持收起任务、切换隐藏状态、手动添加与移除任务，并可撤销最近操作。
- **钥匙清单：** 汇总正在追踪的任务所需钥匙，查看相关任务；新出现的钥匙会提示确认是否已有。
- **地图点位：** 查看任务目标、来源图片和地点说明；按地图与楼层查看底图，缩放、拖动、标记到访点位及绘制路线。切换楼层只更换底图，地图标点仍显示该地图所有楼层的任务。
- **藏身处规划：** 选择设施和目标等级，自动纳入前置设施要求，并统计所需材料；可填写已有数量。
- **个人设置：** 支持独立玩家账号、PvE／PvP 档案、中英文界面和明暗主题。每个账号的任务进度与个人资料彼此隔离。

## 安装与启动

### Windows 可执行文件

目前暂无可下载的 Windows Release。后续版本会由 GitHub Actions 自动构建并发布到 [GitHub Releases](https://github.com/xxtra1112/eft-task-assistant/releases)；发布后下载对应版本的 `EFTTaskAssistant-v版本号-Windows-x64.exe` 并运行即可。

程序会启动本地网页服务并尝试打开浏览器。首次使用时，在这台电脑上创建管理员账号。

默认网页地址是 `http://127.0.0.1:8765/`。如果端口已被占用，程序会依次尝试 `8766` 到 `8785`；请使用启动窗口打印的地址和端口。使用期间不要关闭启动程序的终端窗口，关闭窗口会停止服务。预编译程序不需要另装 Python 或 Conda。

发布的程序尚未进行代码签名，Windows 可能显示未知发布者提示。请只从本项目的 Releases 页面下载。

### 从源码运行

需要 Windows、[Conda](https://docs.conda.io/projects/conda/en/latest/user-guide/install/index.html) 和 Python 3.11。在 PowerShell 中执行：

~~~powershell
git clone https://github.com/xxtra1112/eft-task-assistant.git
cd eft-task-assistant
conda create -n eft-task-assistant python=3.11 pip
conda activate eft-task-assistant
python -m pip install -r requirements.txt
python main.py
~~~

首次安装依赖和同步在线任务资料需要网络连接。服务运行时保持终端窗口打开；按 `Ctrl+C` 停止。

## 第一次使用

1. **创建账号：** 第一个账号会成为管理员，必须在运行服务的电脑上通过本机地址创建。玩家名称为 1–32 个字符且不能包含空格；密码至少 8 个字符。之后其他玩家可以自行注册账号。
2. **建立档案：** 新建一个游戏档案，并选择对应的 PvE、常规 PvP 或赛季 PvP 模式。不同档案的任务进度分开保存。
3. **载入任务资料：** 展开“任务清单”中的“从 EFTarkov 任务资料库导入”，选择“同步公开目录”。同步后即可搜索、预览并导入任务。在线资料可能更新或暂时无法访问。
4. **选择截图目录：** 登录后点击“选择截图文件夹”，选择游戏实际使用的 `Screenshots` 文件夹，并在浏览器提示时授权读取。
5. **开始规划：** 检查任务清单、筛选地图、勾选钥匙，并在藏身处规划区选择设施和目标等级。

## 截图识别

助手从**浏览器所在设备**上读取你选择的截图文件夹，不会自动猜测或读取固定的 Windows 用户路径。通常可在 Escape from Tarkov 的截图设置或文件位置中找到 `Screenshots` 文件夹。支持 PNG、JPG/JPEG 和 WebP 图片。

在本机地址 `127.0.0.1` 下，建议使用最新版 Chrome 或 Edge。浏览器支持持续目录授权时，助手会导入最近的截图并监视新截图；如果浏览器不支持该能力，或你通过局域网地址打开网页，则可能需要重新选择文件夹来扫描截图。换浏览器、清除浏览器站点数据或切换玩家账号后，也可能需要重新授权。

识别结果会按截图列出匹配到的任务；匹配成功的任务会自动加入当前档案。OCR 由运行助手的电脑本地执行，不调用云端大模型。识别可能受游戏语言、截图范围、分辨率和界面变化影响，添加后请核对结果。

**截图里暂时看不到某个任务，不代表它已完成。** 助手不会因为任务没有出现在截图中就自动删除或完成它；请在任务清单中手动处理。未匹配的任务可以从公开资料库搜索，或手动添加。

## 任务清单与地图

- 任务卡片里的每项要求可以单独勾选；需要收集多个物品时使用计数。必需要求全部完成后，任务会自动完成。
- 使用商人和地图筛选缩小清单范围；任务清单和地图会保持地图筛选同步。
- 折叠任务可以节省空间。隐藏任务仍保留在档案中，可通过“切换隐藏”重新查看；清空任务清单会移除当前档案中的任务，请谨慎操作。
- 地图右侧按任务分组显示点位和要求。点击标记可查看点位说明；右键标记可切换到访状态。地图支持缩放、拖动、全屏和路线绘制。
- 地图底图及位置资料来自公开来源，可能不完整或与当前游戏版本不一致。请在出发前确认地点和所需物品。

## 藏身处规划

在“升级目标”中选择计划升级的设施和目标等级。目标等级可以设为当前等级；选择目标后，程序会自动纳入其前置设施。下方“升级物品统计”会合并当前计划所需的材料，并允许填写已有数量、查看尚缺数量。卢布和欧元不计入物品件数汇总。

“等级清零”会清除设施勾选和等级计划；“已有数量清零”会清除已登记的材料数量。两者分别操作，不会互相清除。

## 局域网与隐私

默认情况下，服务只接受运行程序的电脑本机连接。要让同一可信局域网中的其他设备访问，可在启动程序前于 PowerShell 设置监听地址：

~~~powershell
$env:EFT_TASK_ASSISTANT_HOST = "0.0.0.0"
$exe = (Get-ChildItem -File 'EFTTaskAssistant-v*-Windows-x64.exe' | Select-Object -First 1).FullName
& $exe
~~~

在运行服务的电脑上用 `ipconfig` 查看局域网 IPv4 地址；其他设备打开 `http://电脑的局域网IP:启动窗口显示的端口/`。如果无法访问，请检查 Windows 防火墙是否允许该程序在**专用网络**通信。不要把端口转发到公网。

局域网模式使用未加密的 HTTP。不要在不可信的公共网络使用，也不要用敏感密码；同一网络中的其他人可能截获密码或会话信息。每台设备都应在自己的浏览器中选择本机游戏截图目录；截图传到运行助手服务的电脑后才会识别，因此其他设备无需、也无法通过服务端路径读取你的本机游戏文件。

账号密码以 PBKDF2 哈希保存。截图识别、任务和档案资料保存在运行服务的电脑上，并按玩家账号隔离；最近截图记录最多保留 10 条。截图文件夹的选择授权则保存在浏览器本机。

藏身处升级目标、已有材料数量、任务和钥匙的显隐状态、地图路线草图等界面资料保存在当前浏览器的本地存储中，并按玩家账号与档案区分。它们不会自动同步到其他浏览器或设备，也不包含在下方服务器数据目录的备份中；清除浏览器站点数据可能会删除这些内容。

助手不把截图发送给云端 AI；同步任务、地图或藏身处资料时，会访问 [EFTarkov](https://www.eftarkov.com/) 和 [Tarkov.dev](https://tarkov.dev/) 等公开来源。

## 数据备份

默认数据目录为 `%LOCALAPPDATA%/EFTTaskAssistant`，其中包含账号、任务、档案和识别记录等数据。要备份或迁移数据：

1. 关闭助手，确保服务已停止。
2. 复制整个 `EFTTaskAssistant` 文件夹到安全位置。
3. 恢复时，将文件夹放回相同数据目录后重新启动程序。

不要在服务运行时直接复制 SQLite 数据库文件，以免得到不完整的备份。备份文件可能包含个人截图和游戏记录，请妥善保管。

## 常见问题

**网页没有打开？** 确认启动窗口仍在运行，并在浏览器手动打开窗口打印的 `127.0.0.1` 地址。若端口被占用，使用窗口显示的后续端口。

**截图没有导入或不再自动识别？** 在 Chrome 或 Edge 中重新选择截图目录并授权。检查选中的是否为实际截图文件夹、文件是否为支持的图片格式。通过局域网访问时，浏览器通常不能持续监视目录，请重新选择目录进行扫描。

**任务漏识别或匹配错误？** 检查截图是否完整显示商人任务列表、界面语言是否与资料相符；先同步公开任务资料，再搜索或手动添加。识别结果仅供核对。

**任务或地图目录无法载入？** 同步公开资料需要互联网连接；来源网站调整或暂时不可用时请稍后重试。已下载并缓存的资料可能仍可使用。

**其他设备连不上？** 确认服务启动前已设置 `EFT_TASK_ASSISTANT_HOST=0.0.0.0`，两台设备处于同一可信局域网，并使用正确的局域网 IP 和启动端口；同时检查 Windows 防火墙。

仍有问题时，请通过 [GitHub Issues](https://github.com/xxtra1112/eft-task-assistant/issues) 反馈。提交诊断信息前，请先检查并遮盖用户名、截图和其他个人内容。

## 开发与构建

在已安装应用依赖的 Conda 环境中，运行以下命令构建 Windows x64 单文件程序：

~~~powershell
python -m pip install -r requirements-build.txt
& "$PWD/build_windows.ps1" -Version 1.0.0
~~~

生成的文件位于 `dist` 目录。构建需要 Windows x64、Python 3.11 和网络连接，以便安装并打包 OCR 运行依赖。源代码欢迎通过 GitHub Issues 反馈问题或提交改进建议。

## 持续集成与发布

GitHub Actions 会在推送到 `main`、提交 Pull Request 或手动运行时检查 Python 依赖与模块导入、Python 编译和前端 JavaScript 语法。推送格式为 `v主版本.次版本.修订版本` 的新标签（例如 `v1.0.1`）后，工作流会在 Windows 上构建可执行文件、启动并检查网页返回 HTTP 200，然后自动创建 GitHub Release，附上程序、许可证、第三方声明和 SHA-256 校验值。

## 数据来源与许可

任务详情、钥匙需求和地图点位主要来自 [EFTarkov](https://www.eftarkov.com/)；藏身处升级材料来自 [Tarkov.dev](https://tarkov.dev/)。这些是社区公开资料，不是游戏官方接口，可能过时、缺漏或与不同游戏模式不完全一致。EFT 当前任务和数据版本会变化，请以游戏内实际内容为准；来源未提供可靠信息时，助手不会推测钥匙获取方法或点位。
