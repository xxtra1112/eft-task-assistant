# 正式版本交付检查

此清单适用于用户明确要求的正式发布，预览包和本地测试构建不自动发布或上传。

1. 确认版本号、Git 提交、更新说明和最终安装包一致；记录最终文件名、大小、SHA256 与构建来源。
2. 检查安装包不含个人数据库、会话、令牌、截图、运行缓存或私有测试记录；保留旧版本与回滚材料。
3. 完成该版本的构建、迁移和实际运行验证，再按已确认的发布范围发布 GitHub 版本。
4. 正式 GitHub 发布时，同步上传同一最新版安装包至用户浏览器中的蓝奏云。
5. 上传前核实浏览器已登录的目标账号、目标文件夹和分享范围；目标不明确时先确认，不猜测目录、不覆盖旧版本。需要本机浏览器交接时在当前软件聊天协调。
6. 上传后核对版本、文件名、大小与本地最终包一致；云端支持下载校验时比较 SHA256，并确认分享链接的实际可访问状态。
7. 只有实际上传成功并完成核验后，才向用户提供蓝奏云分享链接。若未能验证云端内容，明确说明尚未核验的项目。

蓝奏云访问使用用户本地浏览器的登录状态，不在聊天中收集密码或密钥。
