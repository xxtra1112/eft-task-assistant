# 多来源预览：路线同步

此功能位于未发布的本地预览，不代表当前 GitHub 正式版已经包含这些变更。

## 在电脑上绘制

在地图工具栏选择颜色以及细、中、粗三档，再点击“划线”并拖动鼠标。
每条线保存自己的颜色和粗细，后续更换画笔不会改变已画路线。
“撤销线条”和“清除线条”只处理当前来源、当前地图、当前楼层；处理记录可以恢复相应路线。
单层最多 40 条线、合计 12000 个点，单条最多 1000 个点。达到限制时明确提示，原有路线不被静默丢弃。

## 手机和平板

电脑生成二维码后，手机或平板扫码进入只读地图。选择相同来源、地图和楼层时，显示相同路线与样式。
路线通常在下一次约两秒的同步检查后出现；手机不能绘制、撤销、清除或提交路线写请求。
手机暂时失去连接时，保留当前页面已经显示的路线；恢复连接或刷新后重新读取本地服务保存的数据。
手机地图可以独立选择楼层，不能把其他楼层的路线叠到当前楼层。

## 旧路线

旧版路线没有保存楼层。新预览保留原记录，并导入同一来源、地图的“未分配楼层”存储。
它们不会被猜测放到所有楼层；电脑端会显示旧线数量，可明确将其归入当前楼层。
旧线沿用红色、中等粗细，并保留原坐标。重复刷新和重复导入不会增加副本，也不会复活已经分配或清除的旧线。
不同来源没有共同坐标校准，路线不会跨来源复制或叠加。

## 断线和多个窗口

新路线保存到本地 SQLite；浏览器另外保留尚未提交的操作和有限显示缓存。
电脑短暂失去本地服务连接时，尚未同步的修改保留在浏览器，刷新后可继续提交。
每个操作有独立编号，保存成功但响应丢失时，重新连接不会重复新增或撤销。
如果其他窗口已经修改同一层路线，旧的清除、撤销或替换不会自动覆盖新内容。
页面会显示冲突，核对后可重试，或放弃当前楼层未同步的修改；服务器已保存的数据仍保留。

## 存档范围

已提交路线保存在当前数据目录的 `tasks.sqlite3` 中，与档案一起按来源、地图、楼层隔离。
未提交队列和旧浏览器偏好仍受浏览器地址与端口约束。跨版本统一目录、浏览器偏好迁移及多套有内容存档的冲突选择另行交付，不能根据路线已入库宣称全部存档已统一。
