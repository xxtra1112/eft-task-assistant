# EFT 任务助手 1.1.1

## 简体中文

1.1.1 是一个可靠性修复版本，重点改进截图任务识别与钥匙确认流程。

- **修复截图识别后任务清单为空或任务没有自动加入的问题。** 如果截图处理时任务资料目录尚未就绪，程序会保留这次识别结果，并在目录同步完成后自动重新匹配、查询详情并加入新任务。
- **已在清单中的任务仍会显示识别结果。** 截图通知会标明任务已存在，但不会重复加入或重复查询详情，便于确认识别是否成功。
- **修复钥匙确认弹窗按钮无响应或连续弹窗时状态丢失的问题。** 点击“我还没有”或“我有这把钥匙”后会立即显示确认结果，短暂锁定按钮以避免重复操作，然后继续处理下一把钥匙。
- **切换档案时重置钥匙弹窗计时状态**，避免上一档案的待处理确认影响当前档案。

继续使用原有本机档案和缓存数据，无需重新登录或迁移数据。Windows 用户下载下方 x64 可执行文件即可运行；不需要另行安装 Python 或 Conda。截图识别结果仍建议在游戏任务列表中核对。

## English

Version 1.1.1 is a reliability update focused on screenshot task recognition and key-ownership prompts.

- **Fixes empty task lists and missed automatic imports after screenshot recognition.** If the task catalog is not ready when a screenshot is processed, the app keeps the recognition result and automatically retries matching, loads quest details, and imports new tasks after catalog synchronization completes.
- **Recognized tasks already on the list remain visible in screenshot notifications.** They are identified as already tracked without being imported or queried again, making recognition easier to verify.
- **Fixes unresponsive key-ownership buttons and lost state between consecutive prompts.** Choosing “I don't have it” or “I have this key” now shows immediate confirmation, temporarily disables the buttons to prevent duplicate actions, and then proceeds to the next key.
- **Resets key-prompt timers when switching profiles** so a pending prompt from one profile cannot interfere with another.

Existing local profiles and cached data are preserved; no sign-in or data migration is required. Windows users can run the x64 executable below without installing Python or Conda. Please continue to verify screenshot recognition against the in-game quest list.
