# EFT 任务助手 1.2.0

## 简体中文

1.2.0 更新任务和地图资料来源，并补充经过逐点核对的现场图片。

- 任务目录、目标、钥匙需求和获取方式接入 Tarkov.dev JSON API。赛季 PvP 未提供独立目录时会明确提示，不套用常规 PvP 数据。
- 地图接入 Tarkov.dev 的 SVG 底图、任务区域、地点及撤离/转移标注，保留楼层信息，过滤越界坐标，并显示地图作者与素材许可。
- 为 PvE 工厂“邮递员派特 - 1”和“往事速递”两处已核对点位补充共四张现场图片。补图严格绑定当前任务、地图、点位、楼层及坐标，不按名称或邻近位置猜测；其他点位可能仍无图。
- 桌面及手机端改进点位图片来源校验和加载失败提示。继续保留截图自动识别导入、钥匙复选框联动和手机沉浸地图功能。

升级提示：原有任务和档案不会被清空。旧地图资料会按新来源刷新；旧来源的到访标记不会按名称或近邻自动迁移到新点位，升级后请重新核对地图到访状态。上游中文翻译可能不完整；宣传视频中的额外中文覆层不属于本版产品功能。社区资料不保证对应当前游戏补丁，请以游戏内任务为准。

修复 Windows 本地服务端口复用可能造成多实例请求混淆的问题，桌面和手机服务使用独占绑定。

新增可选启动参数 `--port`、`--mobile-port` 和 `--no-browser`，供独立测试使用；默认启动方式不变。

Windows 用户下载 x64 可执行文件即可运行，不需要安装 Python 或 Conda。请使用随附 SHA256SUMS.txt 核对下载内容。

## English

Version 1.2.0 updates the quest and map data sources and adds individually reviewed waypoint photos.

- Uses the Tarkov.dev JSON API for quests, objectives, key requirements and acquisition methods. A missing seasonal PvP catalog is reported explicitly rather than replaced with regular PvP data.
- Uses Tarkov.dev SVG maps, quest zones, locations, extracts and transits. Retains floor information, omits out-of-bounds coordinates, and displays map artwork attribution and licensing.
- Adds four reviewed photos for two PvE Factory waypoints: Postman Pat 1 and Delivery from the Past. Supplements require the exact current quest, map, waypoint, floor and coordinates; no name or nearest-neighbour matching is used. Other waypoints may have no photos.
- Improves waypoint image source validation and load-failure messages on desktop and mobile. Screenshot auto-import, key-checkbox filtering and the mobile immersive map remain available.

Upgrade notes: existing quests and profiles are not cleared. Legacy map details refresh from the new source. Visits recorded against old waypoint IDs are not guessed onto new waypoints; review visited status after upgrading. Upstream translations may be incomplete. Additional Chinese overlays used in the promotional video are not a product feature in this release. Community data may differ from the current game patch.

Fixes Windows listening-port reuse that could mix requests between app instances. Desktop and mobile listeners now bind exclusively.

Optional `--port`, `--mobile-port` and `--no-browser` switches support isolated testing; default startup behavior is unchanged.

The Windows x64 executable runs without installing Python or Conda. Verify the download against the accompanying SHA256SUMS.txt.
