# 地图与任务数据来源

以下来源接入以 v1.2.0 / a03a2ca 为基线，经 Stage1–4 隔离验收后纳入 1.3.0 发布候选。
日期、数量和图像覆盖对应各次已记录核查，不表示每次启动都会重新验证全部上游内容。
本地候选准备没有推送、打标签或发布 GitHub Release；现用程序与宣传视频保持原状。

RE3MR **不是与其他两源等能力的完整模式**。桌面原图可在应用内查看、缩放和全屏，
没有任务标点也能使用；不能同步任务、生成任务点位、自动转换坐标或假定已有完整中文底图。
没有混用其他来源坐标。将来若接入任务坐标，须逐地图/版本/楼层建立可核验的标定与误差记录；
当前没有未经验证的校准矩阵。robots 异常而拒绝的 7 项继续受限，不猜测替代链接或绕过。

本表任务与地图目录数量来自此前独立核查，不表示 Stage3 又实时刷新了所有来源。
Stage3 对 Factory 一张原图进行了真实读取与应用内显示验收；其他路线回归主要使用已保存的同源样本，
不把样本写入时间当作上游更新日期。具体覆盖和失败重试记录以独立验收报告为准。

## 切换行为

- 电脑端“地图与任务资料来源”按档案记住来源，默认仍为 Tarkov.dev。
  切换刷新地图与可搜索的任务目录；需要新目录时点击“同步公开目录”。
- 已跟踪任务和任务目标完成数、钥匙记录不重建、不清空。原导入来源单独记录在任务来源表，
  不能根据参考链接推断。旧任务仅在稳定任务 ID、模式和唯一目录来源能确定时补记来源；
  钥匙摘要读取该来源的历史目录，并将可确认的旧界面偏好标识映射到明确物品 ID，歧义偏好保留。
- 地图点位仅采用所选来源的同 ID 任务资料，不按相似标题匹配或猜测坐标。目录缺失、
  任务未匹配、无可验证坐标和 RE3MR 参考模式仍显示对应任务要求及进度，并说明点位状态。
  已知其他地图的任务不列入本图；旧目录缺地图字段时，允许识别任务要求中“在海关”等明确地点语句，
  不通过任务标题、钥匙获取位置、“实验室日志”或泛指“码头”等词猜地图；无法确认的关联明确提示。
- 钥匙图标、藏身处资料仍来自 Tarkov.dev，界面明确说明；RE3MR 无任务目录时禁用同步。
- 手机端显示来源和许可链接，随电脑端切换，保持只读。手机无法 POST 切源或任务写接口。
- 底图图片 URL 携带明确来源，避免切换过程中旧图片请求读成新来源。
  迟到的旧来源到访写请求返回 409；不同来源点位前缀不能互用。
- 地图目录、地图配置、SVG 底图按来源和游戏模式分别缓存到数据库旁 source-cache/。
  12 小时内使用本地缓存，超时刷新失败时仅回退该来源上次成功内容并显示警告。
  从未成功缓存的来源显示错误，不能静默替换为另一个来源。
- EFTarkov 的 SVG 像素使用每个楼层自身宽高转换，非法楼层、非有限数、
  超出边界的点位不显示；不套用 Tarkov.dev 的坐标变换。
- 楼层记忆按来源隔离；新路线进入 SQLite，按档案、来源、地图和楼层隔离，手机只读同步。
  未记楼层的旧浏览器路线保留为待分配记录，不猜楼层，不跨来源复制。详见[路线同步](route-sync.md)。
  中文地图/楼层名随来源提供；不能保证所有底图内部文字已经汉化。

## 到访记录迁移与回退

source_migrations 中 map-visits-v1 记录一次性复制迁移：
识别 tarkovdev- 和 eftarkov- 点位前缀，将旧记录分别复制到
tarkov.dev:<map-id>、eftarkov:<map-id>。旧行原样保留；未知来源不猜测。
新标记只修改对应来源空间，重启不会再次复制并复活已取消的到访。

预览构建应先用新建测试档案或数据库副本验收。回退原 v1.2.0 可继续读取旧格式原行；
预览期间新增/取消到访仍保留在各来源空间，但不会自动倒灌旧版。
如要合并回旧格式，应先备份数据库，并只按明确来源导出；不得跨源猜测或删除原始记录。

## 验收重点

1. Tarkov.dev 导入任务、勾选一项到访；切 EFTarkov 后不出现该到访勾。
2. 同一个真实任务 ID 在 EFTarkov 目录中加载本来源详情和工厂 SVG 像素点，
   标注另一项到访；往返切换并重启后两个来源分别恢复。
3. 任务完成数、钥匙状态和藏身处计划保持；来源标签与实际 URL 一致。
4. RE3MR 在桌面显示原始高清底图并保留署名，零任务标点时仍可查看；不借用其他来源任务坐标，受限资源明确显示原因。手机不代理其图片。
5. 断网时只使用已缓存的同来源资料；手机能读地图，不能写切源和任务。

RE3MR 任务点位、公共再托管和再分发仍未实现或授权，不因桌面个人查看成功而扩大使用范围。
共享存档、旧浏览器偏好导入、冲突备份与回滚边界见 [存档协议](save-data.md)。
